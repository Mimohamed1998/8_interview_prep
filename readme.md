# Project Workflow

- [ ] 1. Create separate CSVs and put the data into `data/raw`, sheet by sheet.

- [ ] 2. Data quality (DQ) check
  - [ ] a. Check for outliers.
  - [ ] b. Decide how to handle null values.

- [ ] 3. Clean the raw data and put it into the `processed` folder.
  - [ ] a. Capitalize column names consistently (capital → simple).
  - [ ] b. Remove unwanted characters.

- [ ] 4. Update the project requirements.
  - [ ] a. What is this project about?
  - [ ] b. What are the data sources?
  - [ ] c. What are you trying to solve?
  - [ ] d. Analysis to be conducted:
    - [ ] i. Analysis 1
    - [ ] ii. Analysis 2
  - [ ] e. Modeling requirements.
  - [ ] f. Summarize the result.

- [ ] 5. Have the agent create plans in `docs/plans` for the requirements — do not implement the plan yet.

- [ ] 6. Validate the plans.

- [ ] 7. Implement the plans.

- [ ] 8. Validate the code.

- [ ] 9. Create the final synthesis.

- [ ] 10. Validate the synthesis.

- [ ] 11. Get the graphs and put them into the main table.
